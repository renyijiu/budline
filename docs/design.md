# 一笔护崽 · 设计说明

## 灵感与目标

灵感来自短视频里常见的“画线救狗”类玩法：屏幕上一只动物，画一条线护住它，蜂巢里的蜜蜂扑上来，撑过几秒就算赢。这类玩法好看在于：一大群蜜蜂扑在线上的压迫感、线被推歪时的紧张、角色慌张的表情，以及失败后马上重来。

但只会“画个罩子”的话很快就腻了：画面小、敌人少、线砸到角色直接判负让人挫败、每关解法都差不多。

本作保留“一笔 · 实体物理 · 短倒计时 · 秒重来”的核心，补上让它成为“真正游戏”的部分：

| 方向 | 做法 |
| --- | --- |
| 读得懂 | 全屏竖屏，高对比卡通描边；开局显示每个蜂巢会出几只蜜蜂和胡蜂、炸弹的落点与时间；敌人出手前都有预警（胡蜂红色瞄准线、青蛙粉色虚线、鳄鱼“!”） |
| 有张力 | 蜂群会贴着墨线滑动找缝；越到后面越快；蜂鸣声随附近蜜蜂数量变大；最后 3 秒倒数 |
| 失败公平 | 墨线压到萌宠不会受伤，只有敌人和危险地形会伤害萌宠；萌宠有 3 颗心；失败时慢放并给出具体原因和建议 |
| 解法多样 | 墨水有硬上限，逼你借地形；图钉、木筏、跷跷板、移动平台让“画什么形状”真正有区别 |
| 成长 | 星星 → 蜂蜜 → 道具和萌宠；章节通关解锁新萌宠；无尽模式记录最高波数 |

## 规则

- 每关通常一笔（部分关卡两笔）。线不能穿过地形、萌宠、蜂巢和其他敌人，碰到障碍会像笔尖顶到墙一样停住，绕开后可以继续画。
- 松手后线成为刚体：有重量、会掉落、会被推动。线穿过图钉会被钉住（一个图钉可转动，两个图钉就固定死）。
- 失败：心被扣光，或者掉进水里、岩浆、尖刺、掉出画面，或者被鳄鱼咬到（一击致命）。
- 星级：过关 1 星；毫发无伤 +1；用墨不超过省墨线 +1。

## 威胁设计

| 威胁 | 行为 | 对应的解法 |
| --- | --- | --- |
| 蜜蜂 | 成群追踪，被挡住时贴着线横移找缝；推力弱但数量多 | 线的两端贴地/贴墙，不留缝 |
| 胡蜂 | 靠近后悬停瞄准 0.75 秒，再直线猛冲，质量大 | 把罩子撑在石头之间 |
| 鳄鱼（陆地） | 推着线走；被挡住时会叼起线往上甩，再趁机扑进去 | 穿过两颗图钉把线钉死 |
| 鳄鱼（水中） | 在水里跟着萌宠游，蓄力后跃起扑咬 | 罩子/网挡住跃起的路线 |
| 青蛙 | 瞄准后直线吐舌头，能穿过竹篱笆，碰到墨线会弹回 | 舌头的来路上要有墨线，包括脚下 |
| 炸弹 | 落地后引信燃尽爆炸，**炸断 64px 内的墨线**，炸飞附近的蜜蜂；冲击波会被地形和墨线挡住 | 钉一块斜挡板让炸弹滚走 |
| 落石 | 沿地面滚来，很重；**正面撞上会撞断墨线**，碰到萌宠直接压扁 | 画 20° 左右的缓坡，让它顺着滚上去飞过头顶 |
| 冰面 / 阵风 | 冰面几乎无摩擦，风会推动蜜蜂、墨线和萌宠，也会吹偏正在下落的线 | 钉住、挂住上风处的木桩、顺风提前量 |
| 乌云 | 区域内画不了线，但东西能穿过 | 画在乌云上方，让线掉下去 |
| 塌桥 | 开局不久就会碎掉 | 提前在下面钉一张网接住 |
| 冰锥 | 挂在冰洞顶上，掉落前会抖；**尖端正面砸到会砸断墨线**，碰到萌宠直接扎中 | 屋顶画陡（约 70°），让冰锥擦着坡滑下去 |

## 关卡验证

每关的 `solution` 是一条或几条参考笔画。`tests/levels.test.ts` 会按玩家画线的同一套规则重放每关，要求：

1. 参考解法没有被障碍截断，能拿到 3 星；
2. 什么都不画必定失败；
3. 参考解法整体偏移 5px（模拟手抖），三次里至少成功两次；
4. 除标了 `naiveOk` 的 4 个教学关（1-1、1-2、1-3、2-1）外，对每只萌宠画半径 80/100/125 的半圆罩子、或者一个罩住全部萌宠的大半圆，都必须失败；
5. 关卡里声明的 `pitfalls`（例如 4-5 里不考虑风、正对着画的盖子；4-6 里坡度太缓的屋顶）必须失败。

模拟使用固定 1/60 秒步长、确定性 Rapier 和种子随机数，同样的输入每次结果都一样。

## 已知的不足

- “标准罩子”只是对新手第一反应的近似，不能证明每关只有一种解；玩家可能找到别的巧解，这是好事。
- 竹篱笆、乌云这些机制目前只靠关卡提示文字教学，没有专门的引导动画。
- 尚未在真机手机和 Safari 上测试。
